# Nyami 全局界面体验优化

## 1. 背景与目标

用户要求使用 UI Skills 深度改善全局各界面，并参考历史格式分阶段提交 Git。项目为 React Native 0.74.5 / React 18.2 原生应用，使用 React Navigation、自建主题、MaterialCommunityIcons，已有浅色、深色、浅色玻璃和深色玻璃主题。

保留紫色品牌、音乐封面优先、全局播放导航、既有页面/服务/Store 架构。保持收藏搜索模式、完整播放队列、收藏归属与鉴权边界；播放详情页继续禁止整页滚动。

## 2. 设计依据与约束

- 使用 `ui-ux-pro-max`，查询 Music Streaming 与 React Native 触控/无障碍指南。设计系统查询中的营销页结构与本项目不匹配，不套用；采用适合原生音乐应用的内容优先、深浅成对、48dp 触控、语义色与清晰状态原则。
- 使用 `web-design-guidelines` 中平台无关的可访问名称、内容溢出、异步反馈、动画和触控检查；HTML/ARIA/CSS 专属规则不直接套用到原生组件。
- 使用 `git-advanced-workflows`，改动前工作区干净，历史使用中文 `fix:` / `feat:` / `style:` / `perf:` 等提交格式。仅精确暂存本次文件，不推送。
- 不新增 UI 依赖，不替换技术栈，不修改播放、网络、数据库及账号业务契约。

## 3. 已确认问题

1. `GlassView` 默认背景在非玻璃浅色模式下仍回退到深色 RGBA，且默认启用模糊及多层装饰；普通主题缺少正确表面基底。
2. 公共 `IconButton` 视觉区域仅图标大小加 12dp padding，多处不足 48dp；部分操作无可访问名称。`Button` 固定高度及文字按钮过小，放大字体易挤压。
3. 浅色/深色 `textHint`、部分状态色和主色按钮前景配对需要提高对比；玻璃主题需为浮层提供稳定不透明表面。
4. 页头左右固定 40dp，多个操作并排容易侵占标题；列表副标题单行截断设置说明。
5. 各页面存在搜索栏和排序操作偏小、10px 标签、固定高度头图区、大标题与工具栏争宽、安全区不一致等情况。细节在阶段完成后补充。

## 4. 阶段计划

1. 主题与公共组件：语义色、表面、按钮、页头、空/错误/加载态、弹窗、全局播放导航及滑块无障碍。
2. 内容浏览与音乐库：首页、发现、搜索、推荐、画像、收藏夹与视频详情、偏好列表及同步详情。
3. 播放与设置：播放页、操作面板、音效、登录、启动页和设置，统一复查与验证。

## 6. 实施与验证记录

### 阶段一：主题与公共组件

- 延续紫色品牌，普通主题使用安静的中性底色和独立卡片表面；补充 `surfaceRaised`、`surfacePressed`、`overlay` 及状态前景色。浅色提示文字和成功文字经过计算进一步加深，使其在次级表面仍能阅读。
- 玻璃表面提高基底不透明度，普通主题不再使用深色玻璃回退；`GlassView` 从多层色边/颗粒/强阴影收敛为单一边框与轻阴影，保留 `noBlur`、`minimal`、`constrainContent` 契约。
- 公共图标、按钮、滑块和播放进度触控区域按至少 48dp 设计；按钮支持放大文字自然增高，加载态报告 busy/disabled，补图标名称与禁用语义。
- `Header` 根据左右操作实际宽度保留对称区域，考虑系统安全区；`ListItem` 允许设置说明换行。
- `Dialog`、收藏选择和队列面板使用稳定不透明表面；对话框适配短屏和长内容，操作可纵向排列。收藏名称输入适配键盘，私密选择提供 checkbox 语义，保留当前默认行为。
- 加载态收敛为原生进度指示与文字，空态/失败态提供清晰层级和重试入口；通知使用实际安全区、可滚动完整消息和关闭按钮，触摸消息时暂停自动关闭。
- 新增系统减少动态效果 hook，应用于底栏、背景与对话框/队列面板。底栏选中状态覆盖歌曲推荐路由，标签统一为“音乐偏好”，保留全局单实例播放器。
- MiniPlayer 保留独立状态订阅和轻量表面；窄于 360dp 时收起下一首快捷按钮，仍可打开完整播放器使用下一首，给歌名留出空间。底栏本身参与正常布局，不需要页面额外预留 132–136dp。
- 修复公共 `Slider` 的 PanResponder 持有首轮 props 问题：触摸事件读取最新回调/禁用/范围，步长从最小值起算并二次限幅，滚动或弹层打开后重新测量。为 Slider/ProgressBar 增加读屏增减动作；时长无效时禁用进度手势。
- 播放队列默认主行 72dp、分 P 行 48dp；审查发现固定行高在系统 3 倍字体下会溢出，改为根据 `fontScale` 计算一致的行高，并把相同高度传给渲染、展开区域和 `getItemLayout`，保留分页和队列状态逻辑。

验证：基础组件及全部界面 ESLint 在关闭仓库既有 `prettier/prettier` 格式规则后 0 error；没有全仓格式化。原始 lint 存在大量 CRLF/排版错误和内联样式 warning，不能称为完整 lint 通过。完整 TypeScript 与修改前日志逐行比较，新增诊断为 0，既有失败仍保留。

Android 验证使用本机 Android Studio JBR 21 和离线 Gradle 8.6：`:app:assembleDebug --offline` 成功（433 tasks，46 executed），产物为 arm64-v8a / armeabi-v7a Debug APK。Metro Android `--dev false` 打包成功，22 个静态资源已复制。Debug 原生构建与生产 JS bundle 是两项独立验证，不表示已经安装或运行应用，也不表示签名 Release APK 已交付。
