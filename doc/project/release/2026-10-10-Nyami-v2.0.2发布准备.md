# Nyami v2.0.2 发布准备

## 1. 背景与目标

在四项首页与 B 站授权改动提交后，将 Android Release 版本推进到 2.0.2，更新仓库首页的版本指引和 `release/` 更新日志，并产出可校验的 Release APK。

## 2. 现状与范围

- 当前基线为 `main` 上 v2.0.1 发布元数据（Android `versionCode 2`、`versionName 2.0.1`）。
- v2.0.2 纳入 B 站授权续期修复、首页推荐自动/手动刷新设置、刷新路径缓存优化，以及冷启动收藏夹最新视频同步开关。
- 本次构建目标为 Android；不改动 iOS 构建版本和 JavaScript 包版本。

## 3. 方案与核心修改

- Android `versionCode` 递增为 3，`versionName` 更新为 `2.0.2`；设置页版本显示同步更新。
- 新增 `release/RELEASE_NOTES_v2.0.2.md`，并将 README 当前版本链接指向该日志。
- Release APK 按项目 ABI 拆分配置输出 ARM64 与 ARMv7 两个包。

## 4. 验证

- `git diff --check`：通过。
- 执行 `android\\gradlew.bat :app:assembleRelease --no-daemon --console=plain`：`BUILD SUCCESSFUL in 2m 10s`。
- ARM64 与 ARMv7 APK 均通过 `apksigner verify`，单签名者，v1/v2 签名校验通过；`aapt dump badging` 确认包名为 `com.bilimusic`、`versionCode 3`、`versionName 2.0.2`。
- ARM64：`android/app/build/outputs/apk/release/app-arm64-v8a-release.apk`，24,303,547 bytes，SHA-256 `0515AD0FD465B97515011E6F858269D905D89C6A0F11EFDF1E31DAF30C1EA311`。
- ARMv7：`android/app/build/outputs/apk/release/app-armeabi-v7a-release.apk`，19,110,876 bytes，SHA-256 `FBA0A755B787EC112D564EEC761DB90E711057162ED1D8F07FD033F354B6CF98`。
- 未执行真机安装验证。构建提示 Android Gradle Plugin 8.2.1 对 `compileSdk 35` 尚无正式兼容声明，并提示 Gradle 9.0 相关弃用项；本次构建未因此失败。

## 5. 最终结果

Android v2.0.2 Release 已生成并完成签名、版本元数据和哈希校验。两种 ABI 安装包均可从上述路径取得；设备运行表现仍待真机验证。
