# 播放详情页跨来源收藏标记

## 1. 背景与目标

歌曲从个性化推荐等来源加入自建收藏夹后，播放器队列已更新收藏夹关系，但播放详情页原先只在“本地收藏夹播放”时显示收藏状态，导致心形仍为空心。

## 2. 方案与修改

- 本地收藏夹播放继续以当前播放目录关系为准；从该目录取消收藏后，心形立即变为空心。
- 其他播放来源改为读取当前歌曲的 `folderIds`；歌曲属于任一自建收藏夹时显示实心心形。
- 依赖收藏 outbox 对播放队列关系的本地即时更新，因此不等待 B 站远端确认。

## 3. 风险与影响

`folderIds` 只表示本地自建收藏夹关系，不代表订阅的 B 站合集或他人收藏夹来源。若队列数据尚未合并本地关系，播放页仍会按当前可用快照显示；收藏操作成功后，队列会即时更新。

## 4. 验证

- 静态检查：确认播放详情页区分当前目录收藏状态和跨来源的本地收藏关系。
- `git diff --check`：提交前检查补丁空白错误。
- 尚未执行 Android 构建或设备交互验证。

## 5. 结果

同一首歌曲加入收藏夹后，个性化推荐等来源的播放详情页会显示实心心形；本地目录取消收藏仍按当前目录状态显示。
