# 标签与全局索引后台同步通知

## 1. 背景与目标

用户需要在全局索引同步、收藏视频标签回填时切换到手机后台，且在 Android 通知栏看到当前进度。

## 2. 现状与关键证据

- `src/store/syncStore.ts` 通过 `favoriteService.syncGlobalIndex` 执行全局索引同步，并持有已处理视频数、总视频数和列表计数。
- `src/services/tagRecommendationService.ts` 的 `backfillFavoriteTags` 为标签同步提供已完成/总视频数；自动回填和画像页手动生成都会调用它。
- `AndroidManifest.xml` 当前只声明媒体播放类型的前台服务权限，没有 `dataSync` 前台服务声明；项目 `targetSdkVersion` 为 35。
- Android 官方文档说明：target 35 的 `dataSync` 前台服务需声明类型和对应权限，Android 15 对该类型增加累计 6 小时/24 小时时限；Android 12 起应用在后台时通常不能启动前台服务。因此应在用户仍处于应用前台时启动服务，再允许用户切出。
  - [Android foreground service types](https://developer.android.com/develop/background-work/services/fgs/service-types)
  - [Android 15 behavior changes](https://developer.android.com/about/versions/15/behavior-changes-15)
  - [Restrictions on starting a foreground service from the background](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)

## 3. 方案设计与取舍

采用 Android `dataSync` 前台服务承载进行中的 JS 同步任务，并由 React Native 原生模块更新一个带进度条的持续通知。同步进度继续来自现有 JS 回调，不搬迁业务请求、账号 Cookie 使用或 WatermelonDB 写入逻辑。

候选方案包括：

- `dataSync` 前台服务：能为当前 React Native 进程提供用户可见的进行中通知，改动集中，适合用户主动开始后切到后台的同步。
- WorkManager / user-initiated data transfer job：更适合可在进程重启后恢复的持久任务；当前业务全部运行在 JS 服务中，采用它需要建立新的原生 Worker 与 JS/数据库任务桥接，超出本次最小改动范围。

采用前者；服务从同步被触发时的前台页面启动。通知权限被拒绝、进程被系统结束、Android 15 服务时限耗尽时的行为需明确保留边界。

## 4. 影响范围

- Android Manifest、原生 `Service`/`NativeModule`/`ReactPackage`。
- JS 通知进度适配器，以及全局索引和标签回填的进度回调。
- 不变更数据库结构、网络接口、账号数据格式或同步游标。

## 5. 验证方案与结果

- Android `:app:compileDebugKotlin` 编译通过，包含新增前台服务、React Native 原生模块和包注册。
- 全量 TypeScript 检查未通过，报错来自既有 `favoriteService.ts` 联合类型、`trackPlayer_backup.ts` 和 `tests/` Jest 类型；筛选本次修改文件未发现 TypeScript 诊断。
- 新增的 `backgroundSyncNotification.ts` ESLint 检查为 0 个错误、9 个项目风格警告（`curly`/`no-void`）。对多个既有源文件执行 ESLint 会报告大量全文件格式诊断，因此没有自动重排这些文件。
- 未新增或运行测试。通知栏实际展示、切后台后同步是否持续、通知权限拒绝以及 Android 15 服务超时行为尚未真机验证。

## 6. 当前状态

已增加 Android `dataSync` 前台服务和进度通知桥接。全局索引同步把现有同步计数推送到通知；自动收藏标签回填用跨批次累计进度更新同一通知，画像页手动标签补齐也显示单独的任务进度。索引和标签任务并行短暂重叠时，通知汇总活动任务并在最后一项完成后延迟移除。

通知服务需在应用仍处于前台时启动；Android 12 起从后台启动前台服务受限。Android 13+ 若用户拒绝通知权限，通知栏展示可能受系统权限影响。项目 target SDK 为 35，Android 15 对 `dataSync` 服务施加每 24 小时累计 6 小时限制；当前实现不持久化进程重启后的 JS 任务。以上属于平台行为边界，待目标设备验证。参见 [前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types)、[Android 15 行为变更](https://developer.android.com/about/versions/15/behavior-changes-15) 与 [后台启动限制](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)。
