# 移除收藏夹多选功能

## 1. 背景与目标

收藏夹首页的多选入口、选择状态和“混合播放”工具栏不再符合当前交互需求。此次改动移除整个多选操作链，同时保留收藏夹浏览、单曲随机播放、搜索和新建收藏夹。

## 2. 现状与排查

- `FoldersScreen` 是 `selectionStore` 的唯一消费者；全局选择状态仅用于选择用户创建的收藏夹并生成混合播放队列。
- 收藏夹卡片在多选模式下会改变点击语义、禁用外部列表并显示复选框；页面顶部工具栏负责开关模式，底部工具栏负责执行混合播放。

## 3. 核心修改

- 移除顶部多选切换按钮、收藏夹选择复选框、底部混合播放栏及其队列拼接逻辑。
- 收藏夹卡片始终保持原有导航行为；右侧进入提示始终显示。
- 删除无其他消费者的 `src/store/selectionStore.ts`，从收藏夹屏幕移除相应状态与导入。

## 4. 影响与验证

- 影响范围仅限收藏夹首页的批量选择/混合播放；既有全局随机播放、单个收藏夹/合集查看、收藏夹新建、全局搜索不依赖该 Store，继续保留。
- 静态检索确认 `selectionStore` 不再有运行时代码引用；通过 `git diff --check` 检查补丁格式。未运行构建、测试或设备验证。
