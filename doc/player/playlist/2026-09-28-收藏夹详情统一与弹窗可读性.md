# 收藏夹详情统一与弹窗可读性

## 1. 背景与目标

用户反馈“我创建”的收藏夹详情与“订阅合集”详情样式不一致，排序方式和播放器选集弹窗在玻璃主题下背景过透、文字难辨。

## 2. 根因

- `VideosScreen` 对外部来源使用大尺寸封面 hero，对自有收藏夹使用普通 Header 加小封面卡片，标题区和视觉层级不同。
- 排序/操作弹窗使用主题 `background`，玻璃主题下该颜色为透明；播放器选集弹窗复用了半透明 player/glass overlay 色。

## 3. 方案与核心修改

- 自有收藏夹和外部来源共用封面 hero、返回按钮、类型标签、视频数及标题；无封面时使用音乐文件夹图标占位。
- 自有收藏夹标签显示“我创建”；外部来源按既有来源类型显示“收藏夹”或“订阅合集”。外部 UP 主和简介仍只在来源提供时显示。
- 收藏夹排序与操作弹窗、播放器选集弹窗使用不透明浅色/深色表面底色，保留现有蒙层、文字和交互。

## 4. 风险与验证

- 详情顶部统一为 252px hero，高度与外部来源详情一致；小屏安全区域和不同标题长度仍需真机查看。
- 静态检查确认两处弹窗背景不再使用透明玻璃背景；未运行测试、构建、lint 或真机视觉验证。
