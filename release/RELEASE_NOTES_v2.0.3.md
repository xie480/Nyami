# 🎵 Nyami v2.0.3 发布说明

> 发布日期：2026-10-19

v2.0.3 聚焦收藏搜索与播放队列修复，并统一主题、内容浏览、播放、设置与音效界面的交互体验。

## ✨ 界面与交互改进

### 主题与基础体验

- 统一浅色、深色和玻璃主题的表面与文字层级，提高提示文字、状态和弹窗的可读性。
- 优化按钮、底部导航、滑块和进度条的触控区域与无障碍语义，支持系统减少动态效果设置。
- 改善弹窗、通知、加载、空白和错误状态，长消息可滚动查看，失败操作提供清晰的重试入口。

### 发现、搜索与音乐库

- 调整发现、搜索、推荐、收藏夹和音乐偏好页面的信息层级，统一封面、筛选与列表操作。
- 改善短屏、放大字体和安全区适配，减少列表底部重复留白。
- 设置页按账号、主题及功能分组组织，完善开关说明与关键词管理。

### 播放与音效

- 播放详情页根据可用空间调整唱片与控制布局；加载时可退出，播放失败时可主动重试。
- 改善播放队列的大字体布局、展开分 P 和定位一致性。
- 完善 EQ 参数说明与滑块读屏操作，区分横向浏览频段和纵向调节，减少手势冲突。
- 优化播放更多、睡眠定时、登录二维码与启动页的展示。

## 🐛 问题修复

- 恢复收藏夹“关键词 / 作者”搜索模式，两个搜索入口使用一致规则；切换模式保留输入，播放队列刷新继续沿用当前搜索条件。
- 修复收藏搜索只将前 100 条结果加入播放队列，导致后段歌曲无法正确选择的问题。
- 修复播放队列面板的高度与滚动约束，使长队列可以在受限区域内浏览。
- 修复连续选歌、切换播放来源或账号时，旧请求干扰当前选择和错误提示的问题。
- 修复普通浅色主题部分组件使用深色玻璃背景，以及滑块读取旧回调、禁用或范围状态的问题。
