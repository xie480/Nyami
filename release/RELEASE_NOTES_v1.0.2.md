# 🎵 Nyami v1.0.2 发布说明

> 本次更新主要聚焦于后台播放稳定性的深度优化与核心播放队列的重构，彻底解决了多场景下的切歌中断问题，并进一步提升了应用的整体流畅度。

---

## ✨ 优化与改进

- **播放架构**：重构了 `loadQueue` 核心逻辑，实现了动态滑窗机制，大幅提升了播放列表的管理效率
- **加载机制**：优化了音频的批次预加载机制，提升了弱网环境下的加载体验
- **交互体验**：在切曲过快时添加了防抖锁和弹窗提示，避免了频繁操作导致的播放异常

## 🐛 问题修复

- **后台运行**：修复了后台播放时 JS 线程被系统杀死的问题，以及后台定时器挂起的 Bug，显著提升了后台播放的稳定性
- **播放控制**：彻底修复了缓存情况下及后台播放时可能出现的切歌中断问题，解决了播放列表切歌异常的 Bug
- **状态同步**：修复了锁屏状态下 Cookie 丢失的问题，确保了账号状态的持久有效

---

## 📦 安装与更新

- **系统要求**：Android 7.0+  
- **安装方式**：下载 APK 文件直接覆盖安装即可
