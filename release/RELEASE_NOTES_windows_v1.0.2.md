# NYAMI Windows v1.0.2

## 新增与修复

- 降低 PC 端全局索引同步并发度，减少触发 Bilibili 限流的概率。
- 增加“仅同步导入收藏夹”入口。
- 修复窗口最小化后歌曲结束无法自动切歌的问题。
- 修复 Windows 任务栏、托盘和通知使用 Electron 默认图标的问题。
- 修复 Windows 通知点击后未恢复 NYAMI 客户端窗口的问题。
- 首次登录且没有本地全局索引时发送一次同步提醒，避免重复打扰。

## 已知限制

- 更新检查仍只读取清单并打开下载地址，安装需要用户手动确认。
- 当前构建未配置 Windows 代码签名证书，安装包可能显示系统安全提示。
- Windows 10/11 安装、覆盖升级、通知点击和后台播放仍需在目标系统完成实机验收。
