# 🎵 Nyami v2.0.1 发布说明

> 发布日期：2026-10-03

v2.0.1 聚焦播放页收藏体验、收藏夹最新内容刷新，以及网络变化后的加载和播放恢复。

## ✨ 新功能与改进

### 收藏夹内容刷新

- 冷启动并完成登录后，自动检查当前展示的收藏夹和已选合集中的最新视频，减少新内容迟迟未出现在本地列表中的情况。

### 网络恢复

- 网络恢复或在线网络类型切换后，自动重试当前页面已失败的数据加载。
- 自动恢复被网络中断的播放，并重试待处理的收藏操作和索引同步任务，无需重启应用。

## 🐛 问题修复

- 修复从首页搜索结果以及部分收藏歌曲进入播放界面时，收藏按钮缺失的问题。
- 修正全局播放队列的来源上下文处理，避免沿用上一队列的信息导致收藏入口显示不正确。
