# 🎵 Nyami v2.0.0 发布说明

> 本次版本以 v1.0.2 提交 `af48d47` 为基线，整理至 `51db332`（2026-09-30）。

v2.0.0 在原有收藏夹同步与音频播放能力上，扩展了发现、搜索、个性化推荐和跨来源歌单体验，并集中改进播放页、同步效率与播放稳定性。

## ✨ 新功能

### 登录与 Bilibili 内容接入

- 增加 Bilibili 二维码登录和登录态刷新能力；修复登录流程，并在请求日志中隐藏 Cookie 内容。
- 支持同步已收藏的他人收藏夹和已订阅合集，可在主页播放列表偏好中选择显示，并浏览、播放其中的视频。
- 增加 Bilibili 站内视频搜索与收藏操作，搜索结果支持滚动加载、按展示顺序加入播放队列，也可加入 B 站收藏夹。

### 发现与个性化推荐

- 新增发现页、全局底部导航和全局迷你播放器，主页可展示个性化推荐。
- 根据本地收藏视频的标签生成兴趣画像，提供歌曲推荐，并从已收藏的他人收藏夹和订阅合集中挑选推荐歌单；以图表展示画像和推荐依据。
- 推荐内容支持分页加载、下拉刷新和订阅；订阅的推荐合集会加入本机收藏目录并触发索引与标签同步。
- 首页推荐按 5 小时周期更新，并过滤过去 7 天内的重复内容；推荐不足时会继续补充，合集列表支持滚动加载。
- 改进全局索引和随机播放，减少重复曲目，并完善搜索、推荐列表的播放队列顺序与续播行为。

### 播放器与音效体验

- 重构沉浸式播放详情页，加入唱片视觉、随音频律动的频谱环，以及从封面提取的主题色背景。
- 支持调整播放页背景模糊度、设置定时暂停，并可从播放页直达对应的 Bilibili 视频详情。
- 改进进度条拖动与定位、播放控制和 EQ 实验室界面；优化频谱渲染负载与播放页导航体验。

## ⚡ 优化与改进

- 收藏和取消收藏采用本地即时反馈，并在后台同步及重试；播放页可直接取消当前收藏，并同步不同来源的收藏状态。
- 持久化用户画像、收藏夹目录和标签数据，减少重复加载；优化索引与标签回填流程，支持后台同步进度通知。
- 优化首页、合集和搜索推荐的分页、刷新、队列补充与缓存复用，改善加载和播放响应。
- 改进底部导航、设置页导航和加载期间的页面切换响应；整理项目目录与测试文件结构。

## 🐛 问题修复

- 修复播放地址缓存串歌、队列补充竞态、播放错误后无法恢复及播放列表耗尽后停播等问题。
- 修复播放页卡死、频谱轮询渲染负载偏高，以及快速切歌请求处理异常。
- 修复收藏状态反馈、跨来源收藏标记和收藏夹目录刷新期间的过期结果问题。
- 修复首页推荐及合集分页的重复、数量不足、刷新和触底更新问题。
- 修复加载期间无法切换页面，以及登录和收藏夹页面的状态更新问题。

## 🧰 工程改进

- 增加 Android 手机一键构建与测试脚本，修正 Windows PowerShell 脚本兼容性并处理 Ninja 缓存路径问题。
- 集中整理 Jest 单元测试、手动诊断脚本和 iOS 测试文件目录。
