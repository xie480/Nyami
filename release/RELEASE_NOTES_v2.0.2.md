# 🎵 Nyami v2.0.2 发布说明

> 发布日期：2026-10-10

v2.0.2 聚焦 B 站授权续期稳定性、首页推荐刷新控制与速度，以及启动时的收藏夹最新内容同步策略。

## ✨ 新功能与改进

### 首页推荐刷新

- 支持选择自动或手动刷新。自动模式可选择 1、3、5、8、12 或 24 小时间隔，默认每 5 小时刷新；手动模式仍可主动刷新。
- 首页推荐复用 5 分钟有效期内的收藏夹来源目录缓存，减少重复请求并缩短刷新等待。

### 收藏夹最新内容同步

- 设置页可控制应用冷启动后是否自动检查当前可见收藏夹和已选合集的最新视频，默认开启；关闭后仍可手动执行全局索引同步。

## 🐛 问题修复

- 修复 B 站授权续期读取页面参数失败，导致续期总是提示失败的问题。
